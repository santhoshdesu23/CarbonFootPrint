# CarbonWise AI

A premium carbon intelligence platform built with Vite, React, TypeScript, Tailwind CSS, Zustand, Zod, React Hook Form, and Recharts.

## What makes this project different

- Carbon Twin simulator for high-signal what-if projections.
- Impact amplifier that translates footprint reductions into trees, miles avoided, and community-scale climate gains.
- Local recommendation engine with no external AI API dependency.
- Fully typed modular architecture with validated forms and tested core logic.
